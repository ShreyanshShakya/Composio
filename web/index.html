    Research Methodology

    • Adaptive research: 3 default pages -> targeted if confidence < 0.8
    • Source priority: Official docs -> Auth docs -> Pricing -> Marketplace
    • Evidence-first: Every claim tied to quoted source
    • Fixed vocabulary: Enums prevent hallucinated labels

    LLM Prompt Philosophy

    • "Unknown is better than hallucinated"
    • Distinguish API existence from credential accessibility
    • Self-serve = developer can get credentials without sales
    • MCP = public server exists (not just Composio toolkit)
    • Buildability: ready -> caveat -> outreach -> blocked

    Tech Stack

    • LLM: NVIDIA Nemotron 3 Ultra
    • Web Research: Firecrawl via Composio
    • Validation: Pydantic + repair retry
    • Orchestration: Python asyncio (5 concurrent)
    • Analysis: pandas + Plotly

    Local Execution

    # Setup
git clone https://github.com/yourusername/composio-app-research
cd composio-app-research
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your API keys

# Run research (resumes automatically)
python scripts/run_research.py

# Create verification sample
python scripts/verify_sample.py

# After manual verification, calculate accuracy
python scripts/verify_sample.py --calculate

# Build case study
python scripts/build_case_study.py

# Serve locally
cd web && python -m http.server 8000
